# 🇬🇧 A la Carta

## Description

A la Carta is a digital restaurant management solution built on Microsoft Power Platform.

The solution consists of four interconnected Power Apps applications designed to manage the complete restaurant ordering process, from customer interactions to kitchen operations and administrative management.

### Applications

- **Customer Menu**
- **Kitchen Display**
- **Staff Command**
- **Admin Management**

All applications are connected through a common SharePoint environment composed of multiple lists that act as the central data repository.

Additionally, the solution includes two Power Automate workflows:

- **CloseOrder**: Responsible for closing and archiving completed orders.
- **SendDigitalInvoice**: Responsible for generating and delivering digital invoices to customers.

The platform centralizes restaurant operations while providing a modern digital experience for customers and staff.

# 🇪🇸 A la Carta

## Descripción

A la Carta es una solución de gestión para restaurantes desarrollada sobre Microsoft Power Platform.

La solución está compuesta por cuatro aplicaciones Power Apps conectadas entre sí, diseñadas para gestionar el ciclo completo de pedidos del restaurante, desde la interacción con el cliente hasta la gestión operativa y administrativa.

### Aplicaciones

- **Customer Menu**
- **Kitchen Display**
- **Staff Command**
- **Admin Management**

Todas las aplicaciones comparten una misma fuente de datos basada en un entorno de SharePoint compuesto por varias listas que actúan como repositorio central de información.

Además, la solución incorpora dos flujos de Power Automate:

- **CloseOrder**: Encargado del cierre y archivado de las comandas finalizadas.
- **SendDigitalInvoice**: Encargado de generar y enviar facturas digitales a los clientes.

La plataforma permite centralizar la gestión del restaurante mediante una arquitectura integrada que conecta clientes, cocina, personal de sala y administración.
